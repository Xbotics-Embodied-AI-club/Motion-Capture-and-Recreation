# FAQ

# 赛题一初赛 · 培训阶段 FAQ

整理自培训答疑中的高频问题，按主题分为四类，可先查目录再定位。

## 一、路径与环境问题

Q1找不到文件，路径定位出错？

答：Anaconda Prompt 不能直接 `cd` 跨盘符跳转，需要先切换盘符或使用 `/d` 参数，例如：

cd /d D:\\openlong\\openlong\_linglong2\.0

这一点在《环境安装指南》背景资料中已有提及，建议先核对当前盘符再执行命令。

Q2测试视频集在哪里获取？

答：官方比赛页面提供了视频集的下载链接，直接从官方渠道获取即可，不需要自行准备。

Q3video path 加载失败？

答：视频集存放地址要和代码里写的路径**完全对应**。排查三步：

- 确认代码中的路径是**绝对路径**还是相对路径，相对路径要以当前工作目录为基准；

- 检查路径中的盘符、斜杠方向（Windows 下建议统一用正斜杠 `/` 或双反斜杠）；

- 确认文件名后缀一致（`.mp4` / `.mov`），无多余空格。

## 二、资产与文件问题

Q4资产文件数量和说明不一样？

答：正常现象。`xml` 文件（MJCF 场景文件）需要**自己创建**——由官方 URDF 通过转换脚本生成，不会直接附带在资产包里，所以数量对不上不影响使用。

Q5执行失败？

答：最常见的原因是**权重和资产没有下载全**。请核对下载清单逐项检查，缺失的文件重新下载补齐后再执行。

Q6转换脚本输出显示 nu=0，是不是出错了？

答：正常。`nu=0` 表示转换后的模型未定义执行器（URDF 转 MJCF 时不携带 transmission 信息），不影响后续的重映射和仿真流程，无需处理。

## 三、运行与报错问题

Q7运行界面卡住，提示 numpy 相关版本（\>1\.22\.4）问题？

答：这是 **numpy 版本安装不对**，安装时其实已经给出过警告。按环境文档固定版本重装即可：

pip install "numpy==1\.22\.4"

重装后重新运行脚本即可恢复正常。

Q8对电脑性能有什么要求？需要多大显存？

答：要求不高，**8G 显存以内的显卡**一般都可以完整跑通全流程，主流游戏本即可满足。

Q9这套代码能不能在 Ubuntu 上运行？

答：可以，完整支持 Ubuntu。《环境安装指南》专门提供了 **Linux 版**文档，按对应版本操作即可。

## 四、输出结果问题

Q10输出的模型视频，怎么真正加载到机器人运行程序中？

答：要先理清输出的层次：

- **视频只是可视化表征**：由 MuJoCo 结合机器人数据与映射结果渲染生成，方便直观检查动作效果；

- **核心是动作序列文件**：重映射得出的关节序列文件（如 37 维关节角 CSV）才是机器人程序真正加载运行的数据。

所以接入机器人时，加载的是序列文件而不是视频。
